Antes de começar

Um sentimentário não é exatamente um dicionário. Aqui, as palavras não são definidas apenas pelo seu significado convencional, mas pela maneira como elas existem dentro de mim.

Cada palavra abaixo está ligada a alguma coisa que me faz lembrá-la: uma música, um poema, uma fotografia, um filme, uma obra ou qualquer outra referência que tenha significado para mim.

Clique nos links para descobrir o que existe por trás de cada palavra.
